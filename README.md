# MUtils Web

This is a Next.js app.

## Requirements

- Node.js **20.x** (recommended: use `nvm`)

This repo depends on native Node modules (via transitive deps). Using Node 20 avoids build failures that can happen on newer Node versions.

If you use `nvm`, you can run:

```bash
nvm install
nvm use
```

## Scripts

```bash
npm ci
npm run dev
npm run build
npm run start
```
